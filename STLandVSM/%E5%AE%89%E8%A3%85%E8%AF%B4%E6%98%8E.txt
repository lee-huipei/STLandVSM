╔══════════════════════════════════════════╗
║   STLandVSM 节点 - 安装说明              ║
╚══════════════════════════════════════════╝

第一步：删除旧节点（如之前安装过）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
打开 ComfyUI 目录，进入 custom_nodes 文件夹，
将原有的 STLandVSM 文件夹整个删除。

第二步：复制新节点
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
将新的 STLandVSM 文件夹复制到 custom_nodes 目录下。
路径：ComfyUI\custom_nodes\

第三步：安装依赖（首次安装需执行）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
在 ComfyUI 目录下打开命令行（在地址栏输入 cmd 回车），
运行以下命令：

   python\python -m pip install -r custom_nodes\STLandVSM\requirements.txt

如果安装速度慢，可以加上国内镜像源：

   python\python -m pip install -r custom_nodes\STLandVSM\requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

安装完成后关闭命令行窗口。

第四步：安装许可证
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
将我发给你的许可证文件夹，复制到\STLandVSM目录下，安装就行。

第五步：重启 ComfyUI
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
启动 ComfyUI，在节点列表中会看到可用节点。

如果启动时看到 [STLandVSM] 开头的提示信息，说明加载成功。

注意事项
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• 本节点为设备绑定授权，更换电脑需重新激活
• 如遇问题，请提供 ComfyUI 控制台输出的 [STLandVSM] 日志
