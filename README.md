# STLandVSM — 灰度图 → 精雕 VSM / STL 3D 模型

> 专为**精雕软件**（北京精雕 / 文泰 / 雕刻机）设计，将 AI 生成的灰度图/深度图转换为可直接使用的 **VSM** 及 **STL** 3D 模型。
>
> 作者微信：**V18959848282**

---

## 🎯 核心用途

**一句话：把灰度图变成精雕软件能打开的 VSM 模型。**

- ✅ 主要输出 **VSM 格式**——精雕软件（北京精雕/文泰/Beihuang/Bowen）直接可用
- ✅ 同时输出 **STL 格式**——通用 3D 打印、CNC 雕刻
- ✅ 支持 16 位灰度 PNG、EXR、TIF 等高精度格式

---

## 📦 包含的节点

| 节点 | 所在文件夹 | 功能 |
|------|-----------|------|
| **📂 加载图像（高精度）** | `STLandVSM` | 替代系统 LoadImage，支持 16位/EXR/TIF |
| **STL & VSM Converter** | `STLandVSM` | 核心：灰度图 → VSM / STL 模型 |
| **Comfy OIIO** | `comfy_oiio` | 灰度图 → 高清 EXR（可选，提升精度） |

> ⚠️ **重要**：系统自带的 LoadImage **无法正确处理 16 位灰度图**（会变成纯黑白），请使用本节点的 **📂 加载图像（高精度）** 来代替。

---

## 🔧 安装

将 `comfy_oiio` 和 `STLandVSM` 复制到 ComfyUI 的 `custom_nodes\` 目录，重启 ComfyUI 即可。

所有图片说明参见仓库中的 `.png` 文件。
